深入六個設計重點

設計做法為什麼
版本集中管理根目錄 parent pom 的 properties + dependencyManagement（BOM 概念）升級或修補漏洞只改一處
共用函式庫bnk-shared：API 信封、核心電文 DTO、遮罩工具各服務格式一致，不重複造輪子
業務模組 / 部署單位分離bnk-mod-account（jar）+ bnk-svc-account（可部署）同一份業務程式可組進不同服務
四層分層api / usecase / domain / infra，一支 API 一個 UseCase 類別職責清楚，好測試、好找程式
API GatewayQuarkus + Vert.x：驗 JWT → 路由 → 非阻塞轉發入口統一做身分驗證，後端只管業務
非同步聚合query → batchId → RabbitMQ → Redis → poll主機慢也不卡執行緒，可水平擴充
主機模擬器bnk-core-emulator：JSON 範本、可設延遲與失敗率不依賴真主機就能開發與測試
全免費工具鏈GitHub Actions + Maven Central + GHCR + PostgreSQL任何人 clone 下來就能跑

為什麼 mod 和 svc 要分開？

mod 只有業務程式，沒有 main()、沒有環境設定；svc 只有 @Import(AccountModuleConfig.class) 加上設定檔與監控。未來要把 account 功能塞進另一個服務，只要再 import 一次。

白話mod 是「引擎」，svc 是「整台車」。同一顆引擎可以裝進不同車款。

bnktest_try 技術介紹5

深入核心流程：query → poll

1

balances/query檢查帳號都屬於登入統編 → 產生 batchId → 先在聚合區建立批次（total=6）→ 每帳號送一筆 BAL001 電文 → 立刻回 {batchId, pollIntervalMs: 500}

2

主機回覆模擬器 0～1.5 秒內陸續回覆，5% 機率回錯誤碼，寫入 batch:{batchId}:results

3

balances/result 輪詢先確認批次擁有者 = 登入統編，再組出已回來的明細與幣別加總；前端用 RxJS timer + switchMap + takeWhile(done) 自動停止。

順序很重要：必須「先建立批次、再送電文」，否則快速的主機回覆可能比批次先到而遺失。

查詢中：已回來的帳號先顯示餘額，其餘顯示「查詢中…」

深入一套程式，兩種執行模式

local（預設）— 零安裝

聚合store=redis：多 Pod 共用

實作方式：同一個介面（CoreGateway、BatchResultStore）兩個實作，以 @ConditionalOnProperty 依設定擇一注入；切換只需 SPRING_PROFILES_ACTIVE=docker。業務程式完全不知道自己跑在哪種模式。

bnktest_try 技術介紹7

深入安全設計

JWT RS256

Gateway 啟動時臨時產生 RSA 金鑰對，Git 裡沒有私鑰；token 30 分鐘到期，竄改即 401。

身分 header 重建

轉發時由 Gateway 依 JWT 重新產生 X-Bnk-*，不沿用前端送來的值，防偽造身分。

越權檢查

前端送的帳號必須全屬登入統編，否則 E003；別人的 batchId 一律回「不存在」。

輸入驗證

Bean Validation（帳號格式、暱稱長度）；MyBatis #{} 參數綁定防 SQL Injection。

不洩漏細節

全域例外處理只回代碼；登入失敗不區分「無此帳號 / 密碼錯」；常數時間比對密碼。

個資與容器

log 遮罩帳號與統編；畫面帳號遮罩；容器非 root；nginx 加資安 header；密碼只放 .env / K8s Secret。

動手跑起來

# A. 零安裝模式（JDK 21 + Maven + Node 22）
mvn install                         # 建置 + 16 個測試
java -jar bnk-svc-account/target/*.jar
java -jar bnk-gateway/target/quarkus-app/quarkus-run.jar
cd bnk-ui && npm install && npm start
# 開 http://localhost:4200  帳號 alice / demo1234

# B. 完整模式（Docker）
cp .env.example .env
mvn -DskipTests install
mvn -pl bnk-svc-account,bnk-core-emulator jib:dockerBuild
docker compose up -d --build

# 壓測
k6 run -e VUS=10 -e DUR=1m k6/smoke.js
